Privacy Policy

VVW Bot is a private, single-user assistant operated by its owner on hardware the owner controls. This policy describes how it handles Google user data.

Who uses this application

Only the owner's own Google Account. The application is not distributed to, offered to, or usable by anyone else. There are no sign-ups and no shared access.

What data is accessed

  • Gmail — reading, searching, drafting, sending, and labeling the owner's own messages.
  • Google Calendar — reading, creating, and updating the owner's own events.
  • Google Drive — reading and storing the owner's own files.

How data is used

Data is retrieved only to carry out tasks the owner explicitly requests, such as summarizing an inbox, scheduling an event, or saving a document. Google user data is not sold, rented, or shared with third parties, and is not used for advertising, profiling, or training machine-learning models.

Where data is stored

OAuth credentials are stored in the operating system keychain on the owner's own computer. Message and calendar contents are processed in memory to fulfill a request and are not retained in any external database. Nothing is uploaded to a server operated by this application.

Third parties

To generate responses, request text may be sent to the language-model provider the owner has configured. No Google user data is shared with any other third party.

Data retention and deletion

The owner can revoke this application's access at any time at myaccount.google.com/permissions, which immediately invalidates its credentials. Locally stored credentials can be deleted from the owner's computer at any time.

Contact

Questions about this policy can be sent to the address listed as the developer contact on the Google OAuth consent screen for this application.
